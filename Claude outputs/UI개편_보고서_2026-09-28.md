**전달본에 없어서 파생시킨 토큰**과 그 근거:

- `--text-mid #504752` — 전달본 `.report-section p`의 실제 색. 리포트 본문에 `--text`를 쓰면 너무 무겁습니다.
- `--surface-sunken #F2ECEF` — 전달본 `.segmented` 트랙 색.
- `--border-strong #CDA7BB` — 전달본 `.button.secondary` 테두리 색.
- `--r-control 17px`, `--r-field 12px` — 전달본 버튼/입력의 실측 모서리. 토큰 표의 14/20/28로는 재현되지 않습니다.
- `--brand-gradient linear-gradient(135deg, var(--brand-dark), #87336D)` — 전달본 주 버튼 배경.
- 상태색 `--success #1F7A5A / --warning #8A5A12 / --error #B3243F` 와 각 soft 배경 — 전달본에는 성공·경고·오류 상태 색이 정의되어 있지 않은데, 이 서비스에는 결제 성공/실패·검증 오류 플래시가 실제로 존재합니다. 브랜드 색조(자주 계열) 안에서 **AA 4.5:1을 만족하는 값**으로 잡았습니다.
- `--rose-text #B23A5C` — `--accent-rose`(#D85878)를 작은 글자색으로 쓰면 흰 배경 대비 3.1:1로 AA 미달이라, 텍스트 전용 로즈를 따로 뒀습니다. 면/아이콘에는 원래 `--accent-rose`를 그대로 씁니다.

기존에 쓰이던 이름(`--paper`, `--ink`, `--seal`, `--gold` 등)은 **삭제하지 않고 새 토큰을 가리키는 별칭**으로 남겼습니다. 약 3,000줄에 걸쳐 쓰이고 있어서 일괄 치환하면 리포트 블록 12종이 전부 회귀 위험에 노출되기 때문입니다.

`color-scheme: light`를 선언하고 기존 다크모드 블록 2개를 제거했습니다. **근거**: 전달본은 라이트 단일 디자인이고, 함께 받은 SVG 7종이 색을 파일 안에 고정해 두고 있어서 다크 배경에서는 그림이 깨집니다. 반쪽짜리 다크모드를 남겨두는 것보다 명시적으로 라이트 전용인 편이 낫다고 판단했습니다. (요구사항에 다크모드 항목은 없었습니다.)

- 직접 실행해 주세요:
  ```

  php artisan test
  ```

**2) Laravel Pint (코드 스타일)**
- 이유: 위와 같습니다. Pint는 `vendor/bin`에 설치되는 composer 패키지입니다.
- 직접 실행해 주세요:
  ```

  (다만 이번 변경은 전부 Blade 템플릿·CSS·SVG이고 PHP 클래스 파일은 건드리지 않아서, Pint가 잡을 것이 있을 가능성은 낮습니다.)

(이번 개편의 CSS는 Vite를 거치지 않는 `public/css/app.css`입니다.)
- 직접 실행해 주세요 (Windows 터미널에서):
  ```

## F. 남은 사항

1. **E-2의 3가지 명령을 직접 돌려주세요.** 특히 `php artisan test`는 제가 돌릴 수 없었습니다.
2. **`welcome.blade.php`는 죽은 코드입니다.** 라우트에 없고, 존재하지 않는 `route('register')`를 부릅니다. 지금 렌더하면 예외가 납니다. 삭제하거나, 쓸 거라면 라우트와 회원가입 기능을 붙여야 합니다. (임의로 지우지 않았습니다.)
3. **저장소에 `:wq` 이름의 파일 2개가 들어가 있습니다.** (`:wq` 와 유니코드 변형 하나) vim에서 저장 명령을 잘못 친 흔적으로 보입니다. 이번 작업과 무관하지만 정리하시는 게 좋겠습니다.
4. **`share-card.svg` 미사용.** 공유 카드를 정적 이미지로 갈 건지, 지금처럼 서버 생성으로 갈 건지 정해지면 반영하겠습니다.
5. **네이버 로그인 버튼 명암비 2.25:1.** 브랜드 가이드 준수 vs AA 준수 중 선택이 필요합니다.
6. **회원가입·비밀번호 재설정·이용약관 페이지는 이 서비스에 존재하지 않습니다.** 전달본에는 관련 화면이 있지만, 없는 기능을 화면만 만들어 두면 "만들다 만 결과"가 되므로 만들지 않았습니다. 필요하시면 기능부터 함께 붙이겠습니다.
7. **다크모드는 제거했습니다** (B-1의 근거 참조). 되살리려면 SVG 7종을 다크 대응 버전으로 다시 받아야 합니다.
